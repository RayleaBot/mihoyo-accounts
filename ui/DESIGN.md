# Design System: 米游社账号 · 名片册

## Overview

**Creative North Star: "名片册"**

「账号管理」是一本名片册。每个已绑定的米游社或 HoYoLab 通行证是一张白卡纸名片：QQ 头像与昵称领头，通行证是名片上的所属机构，游戏角色是头衔。名片三到四张一行插在冷灰册页上，同一个人的名片相邻。需要处理的名片上缘插着一枚写字的索引贴；管理员把名片取出到右侧约 460px 的桌面区，在放大的名片和它的背面上处理角色、设备、云授权与授权插件，处理完放回原位。勾选几张名片，册页底部浮起批量操作条；账号库、密钥保护、ark 令牌与跨聊天关联在册子末页。这个方向明确拒绝「账号表格加状态列」的默认排法。

材料只有纸和墨。册页、桌面区与末页是三种冷灰中性底，名片是白卡纸，边缘一圈细线加一道贴近纸面的短投影；文字是近黑墨色。全页只有一枚专色米游社蓝，留给主操作、取出的名片与焦点；朱红与琥珀只以索引贴出现在册页上。层级只靠字号对比，昵称是每张名片上最大的字；数字一律等宽，名片里的数字列右对齐，同一行名片的数字上下成列。每个状态都附带证据：最近一次检查或刷新的结果与时间印在名片正面。

动效只有一个招牌时刻：取出名片时，view transition 把同一张名片从册页移到桌面区，放回时原路返回；减少动态效果时直接切换。其余只是控件状态的短过渡、折叠箭头的旋转、批量进度条的伸长与读取骨架的微光。

本文件记录 `src/` 中已实现的视觉系统。token 数值以 `src/styles.css` 的 `:root` 为准，每个主题相关的颜色是一对 `light-dark()` 值；头像色在 `src/Avatar.vue`，图标在 `src/Icon.vue`；方向约定见 `.impeccable/surfaces/src-app-vue.md`。

**Key Characteristics:**

- 名片册结构：顶部一条下一步提示带，其下是索引页签、搜索与主操作，主体是名片网格，取出的名片在右侧桌面区，账号库与设置在末页。
- 白卡纸名片：头像与昵称领头，通行证一行，角色逐行列出游戏、昵称、等级与 UID，底部印着状态词与检查证据。
- 一枚专色：米游社蓝只给主操作、取出的名片与焦点；勾选、页签与进度都用墨色。
- 索引贴：朱红表示需重新登录，琥珀表示待检查或需验证，贴在名片上缘、压在名片背后。
- 系统界面字体、等宽数字与同一套 20px 网格的线描图标；不加载外部字体或脚本，外部图片只有经 HTTPS 加载的 QQ 头像。

## Colors

冷灰中性色铺满册页，有职责的颜色只有两类：米游社蓝表示「可以做、正在处理、焦点在这里」，朱红与琥珀索引贴表示「这张名片需要处理」。前置 token 中无后缀项是浅色主题，带 `-dark` 后缀的同名项是暗色主题，二者在 `src/styles.css` 里是同一个 `light-dark()` 变量；`flag-red`、`flag-amber` 及其文字色和 `backdrop` 两套主题共用。主题优先采用宿主同步到根元素的 `data-theme`（它只切换 `color-scheme`），未指定时跟随系统。

### Primary

- **米游社蓝**（`accent`）：主按钮底色（其上文字用 `on-accent`）、取出名片的 2px 外环、键盘焦点轮廓、字段聚焦时的边框与输入光标，以及「扫码添加账号」空位悬停时的虚线。主按钮悬停时混入 14% 墨色。
- **链接蓝**（`accent-ink`）：文字链接与「扫码添加账号」空位悬停时的文字。浅色主题中比 `accent` 深一档、暗色主题中浅一档，保证小字可读。方向约定只列了主操作、取出的名片与焦点三处，文字链接作为动作的一种在构建中补上。
- **选区与聚焦衬底**（`accent-soft`、`accent-ring`）：`accent-soft` 是文本选区底色；`accent-ring` 是字段聚焦时 3px 的外晕。

### Secondary

- **索引贴朱红**（`flag-red`，文字 `on-flag-red`）：需重新登录的名片上的索引贴。它也是破坏性按钮的实底，但这些按钮只在用户发起移除后的确认对话框或确认条里出现。方向约定原文是「红与琥珀只出现在索引贴上」，构建按「静止的册页上」落实，本文件按构建记录。
- **索引贴琥珀**（`flag-amber`，文字 `on-flag-amber`）：待检查、需设备验证、需官方验证的名片上的索引贴。

### 状态文字

- **错误红**（`danger`）：错误文字与错误提示条的图标。
- **需注意琥珀字**（`attention`）：扫码登录中可重试的提示，例如正在退避重试。

### Neutral

- **册页**（`page`）：页面底色，名片直接插在上面。
- **桌面区**（`desk`）：取出名片或添加账号时右侧的桌面区，比册页深一档。
- **末页**（`cover`）：「账号库与设置」所在的末页，明度介于册页与桌面区之间。
- **凹槽**（`well`）：索引页签的轨道、提示带对勾的圆底和批量进度条的轨道。
- **贴片**（`tile`）：名片背面里授权插件的勾选行，以及确认条。
- **卡纸**（`card`）：名片、名片背面、提示带、提示条、批量操作条、对话框、账号库面板与次按钮的底色；按下的页签与分段选项也铺卡纸，像从轨道里抽出的一张。
- **字段底**（`field`）：输入框、下拉与文本框；暗色主题中比卡纸更深，像压进纸面。
- **卡内细线**（`rule`）：名片里通行证行、角色行与底栏的分隔线，名片背面各节之间的分隔线，以及批量结果与跨聊天关联的行线。
- **线**（`line`）：控件边框、空位的虚线、末页各栏之间的竖线、统计行与设置区的顶线。
- **墨色**（`ink`、`ink-2`）：正文与次级文字。`ink` 也是勾选名片的 2px 外环、复选框的强调色、批量进度条的填充，以及合上的册子那枚索引贴的底色；`ink-2` 用于说明、元信息、角色行的游戏名与等级和未按下的页签。
- **悬停底**（`hover`）：带透明度的墨色，用于安静按钮、页签、名片勾选热区的悬停底，以及骨架名片上的微光。
- **遮罩**（`backdrop`）：确认对话框打开时压暗整页。

### 头像色

- **六色首字底**（`tone-0` 至 `tone-5`，各有 `-bg` 与 `-ink`）：蓝、紫、绿、青、沙、石板六组柔和底色配深色首字，按聊天用户 ID 固定取色，同一个人始终同色；真实 QQ 头像加载后盖在上面，失败时露出首字。这组颜色只用于头像。

### Named Rules

**「一枚专色」规则。** 米游社蓝只给三处：主操作、取出的名片和焦点（含字段聚焦外晕、输入光标与文本选区）；文字链接用 `accent-ink`。勾选、页签、分段选项、计数、进度条、状态词和装饰一律不用蓝。

**「红黄只在索引贴」规则。** 静止的册页上，朱红与琥珀只以索引贴出现；名片底部的状态词、提示带和计数都是墨色。朱红实底的破坏性按钮只在确认对话框或确认条里出现；`danger` 与 `attention` 只用于出错和需重试的文字。

**「勾选用墨，取出用蓝」规则。** 勾选的名片加 2px 墨色外环，复选框是墨色；只有取出到桌面区的那一张加 2px 米游社蓝外环。

## Typography

**Display Font:** 无。页面没有展示型字号，最大的字是取出名片上的昵称和账号库面板的标题（22px）。
**Body Font:** 系统界面字体栈（Segoe UI Variable Text，回退 Segoe UI、Microsoft YaHei UI、PingFang SC、Hiragino Sans GB、system-ui、sans-serif），所有角色共用，不下载字体。
**Label/Mono Font:** Cascadia Mono（回退 Consolas、ui-monospace）只用于区服代码与设备标识；数字对齐靠等宽数字特性，不靠等宽字体。

**Character:** 像印出来的名片：清楚、安静、不表演。层级只靠 12–22px 的字号和 400 / 500 / 600 / 650 / 700 五档字重拉开，标题与昵称用 650。

### Hierarchy

- **Headline**（650，22px，1.4）：取出到桌面区的名片昵称，以及合上的册子里账号库面板的标题。
- **Name**（650，18px，1.35）：每张名片上的昵称，单行省略；桌面区「添加账号」标题同字号。
- **Title**（650，17px，1.4）：对话框标题与空态标题；提示带里的计数同字号加重到 700，并用等宽数字。
- **Section**（650，15px，1.4）：名片背面与末页的各节标题，如游戏角色、公共查询池、账号库、密钥保护方式；末页总标题「账号库与设置」为 16px。
- **Body**（400，14px，1.55）：默认正文，段落最宽 72ch。
- **Control**（600，14px，1.2）：按钮、页签与分段选项；名片底部的安静按钮减到 500。
- **Label**（600，13px）：表单字段的标签，堆在字段上方。
- **Meta**（400，13px）：`ink-2` 的说明与元信息、名片的通行证与角色行、联系行、折叠项右侧的状态摘要和页脚。
- **Figure**（400，13px，字距 0.01em，等宽数字）：名片上的通行证 ID 与 UID，在固定宽度的列里右对齐。
- **Tab**（650，12px，行高 18px，字距 0.02em）：索引贴上的字。
- **Code**（Cascadia Mono，12.5px）：区服代码与设备标识，可在任意处断行。

### Named Rules

**「昵称最大」规则。** 每张名片上最大的字是昵称（取出后放大到 22px）；状态、通行证与角色都更小。层级只靠字号对比，不用颜色、徽标或图标给名片排序。

**「数字成列」规则。** QQ 号、通行证 ID、UID、等级和各种计数一律用等宽数字；名片里的等级与 UID 落在固定宽度的列里右对齐（等级列 4.4em、UID 列 7.2em），同一行名片的数字上下成列。联系行里的 QQ 号跟在昵称下方左对齐。


## Layout

页面在宿主 iframe 里居中，内容最宽 1680px，四周留白上 24px、左右 28px、下 32px，纵向各块间距 18px：提示带、名片册（册头、身份说明、册页）、末页、页脚。页面不重复宿主标题、插件名或全局导航，机器人账号由宿主在页面上方切换。

册头一行排开：全选、索引页签（全部 / 需处理 / 可用，各带计数）、搜索框（基准 240px、最宽 360px），右侧依次是刷新列表的图标按钮、「导入 Cookie」与主操作「扫码添加账号」。需要交代昵称来源时（读取中、机器人离线、读取失败或用户只有 openid），册头下方多一行 13px 的身份说明。

册页是自动填充的名片网格，每列最窄 300px，行距 40px、列距 18px，顶部留 26px；行距和顶部留白专为索引贴预留，贴从名片上缘向上伸出 25px。同一个人的名片按首次绑定的顺序相邻排列，同一行名片等高、底栏对齐。在「全部」页签、未搜索且已是最后一页时，网格末尾是一个「扫码添加账号」空位；名片多于一页时，网格下方是居中的分页条。

取出名片或添加账号时，册页右侧出现桌面区：两栏为「剩余宽度 + 380–460px」，间距 24px；桌面区粘在视口顶部下 16px，最高为视口高度减 32px，内容在区内滚动。勾选名片后，批量操作条粘在册页底部上方 16px。

末页在册页之后，三栏以 1px `line` 竖线分隔，栏内左右各 28px：账号库与账号统计、密钥保护方式与 ark 授权令牌、本人跨聊天关联；设置区的字段最宽 420px。

账号库未解锁时，册页只剩一块居中的账号库面板（最宽 560px，距顶部 6vh），页脚随之居中。读取中显示六张骨架名片，列宽与册页相同。

间距按 spacing token 组织：图标与文字 `icon-gap`，操作按钮之间 `action-gap`，勾选行、折叠行与提示条内部 `inline-gap`，册头与桌面区各节 `group-gap`，名片与表单内部 `stack-gap`，名片背面各节上下 `section-y`，名片内边距、页面纵向间距与网格列距 `card-pad`，册页与桌面区之间 `gutter`，页面左右与末页各栏 `page-x`，网格行距 `sheet-row`。

宽度不超过 1180px 时，桌面区移到册页上方、不再粘附或在区内滚动，打开时页面滚动到它；末页改为两栏，第三栏在下方占满整行并以顶线分隔。宽度不超过 720px 时，页面留白收为 16px、各块间距 16px；页签、搜索与册头按钮各占满一行，主操作拉伸；册页单列；账号库面板内边距收为 24px 20px，桌面区 16px，末页 20px 16px 并改为单列；角色表隐藏区服列。验证基准是宿主 1920×1080 下的 iframe，窄屏与粗指针也要可用。

粗指针或宽度不超过 720px 时，按钮、输入框与下拉至少 44px 高，授权插件勾选行与勾选标签至少 44px。页签、分段选项、全选、图标按钮与名片的勾选热区同样不小于 44px。

**「一条提示带」规则。** 册页顶部只有一条下一步提示带：一句话、最多一个动作，按需重新登录、需在官方应用验证、待检查的顺序只说最急的一件；全部可用时它退成一行无底色的次级文字。

## Elevation & Depth

册页、桌面区与末页是平的色面，靠明度分层：名片插在册页上，桌面区比册页深一档，末页介于两者之间。所有卡纸物件（名片、名片背面、提示带、提示条、账号库面板、骨架名片、二维码）共用一层卡纸投影：一圈极细的边加一道贴近纸面的短投影，悬停不抬升。索引贴压在名片背后：每个格位单独建立层叠上下文，贴的下半截藏在名片上缘之下。只有两样东西浮得更高：批量操作条在卡纸投影下再加一道长投影，确认对话框带遮罩和最深的投影。勾选外环、取出外环与字段聚焦外晕虽然用 box-shadow 绘制，但它们是描边，不表示高度。

### Shadow Vocabulary

- **卡纸投影**（`box-shadow: var(--card-shadow)`；浅色 `0 0 0 1px rgb(20 28 40 / 7%), 0 1px 2px rgb(20 28 40 / 6%), 0 6px 14px -8px rgb(20 28 40 / 18%)`，暗色 `0 0 0 1px rgb(255 255 255 / 6%), 0 1px 2px rgb(0 0 0 / 40%), 0 6px 14px -8px rgb(0 0 0 / 60%)`）：所有卡纸物件。
- **按下的选项**（`box-shadow: 0 1px 2px rgb(10 16 28 / 12%)`）：按下的页签与分段选项。
- **批量操作条**（`box-shadow: var(--card-shadow), 0 18px 36px -18px rgb(10 16 28 / 32%)`）：粘在册页底部的批量操作条。
- **对话框**（`box-shadow: 0 28px 64px -20px rgb(0 0 0 / 40%)`）：确认对话框，页面最高的一层，配 `backdrop` 遮罩。
- **头像内缘**（`box-shadow: inset 0 0 0 1px rgb(0 0 0 / 6%)`）：头像圆的内描边，让浅色头像在卡纸上有边。

### Named Rules

**「贴着纸面」规则。** 名片与面板只用卡纸投影：细边加贴近纸面的短投影，悬停不抬升、不加深；册页、桌面区与末页是平的色面。只有批量操作条和确认对话框浮得更高。

## Shapes

圆角随物件尺寸递增：索引贴上沿（`tab`）、轨道里的选项（`inner`）、按钮与字段（`control`）、贴片与确认条（`tile`）、页签与分段轨道（`track`）、提示带与提示条（`strip`）、名片、名片背面、空位与批量操作条（`card`）、对话框（`dialog`）、桌面区、末页与账号库面板（`surface`）依次放大。轨道圆角等于选项圆角加 3px 内边距，内外同心。头像与提示带的对勾底是正圆，批量进度条是胶囊（`full`）。

索引贴只圆上沿两角、下沿方正，下方的内边距藏在名片背后：名片上的贴从上缘向上伸出 25px、距左缘 22px；账号库面板上的贴伸出 23px、距左缘 28px。

边界：控件用 1px `line` 实线；名片内部只用 1px `rule` 横线分隔，不加竖线；空位用 1.5px `line` 虚线。键盘焦点统一为 2px 米游社蓝轮廓、2px 偏移；字段聚焦时边框转为米游社蓝并加 3px `accent-ring` 外晕，不再画轮廓。

图标全部是 `src/Icon.vue` 里的内联 SVG 线描：20px 网格、1.6px 圆头圆角描边、跟随文字颜色。默认 18px（册头按钮、折叠项、提示条），名片底栏、提示带、批量操作条与桌面区的小按钮里 16px，「扫码添加账号」空位里 20px。

**「虚线是空位」规则。** 1.5px 虚线框只表示名片册里的空位：取出名片后留下的格位、网格末尾的「扫码添加账号」空位，以及空册子的示意；悬停可添加的空位时虚线转为米游社蓝。

### 名片

- **结构：** 卡纸底、`card` 圆角、卡纸投影，内边距 18px 18px 12px；三段网格：人、账本、底栏，段间 14px，底栏贴底。

- **状态：** 勾选时外加 2px 墨色环；取出到桌面区后放大：头像 60px、昵称 22px、列出全部角色、去掉勾选与「管理」，外加 2px 米游社蓝环。强制颜色模式下名片加 1px CanvasText 边框，勾选改为 3px Highlight 轮廓。

### 索引贴

- 需要处理的名片在上缘左侧插一枚写字的索引贴：朱红写「需重新登录」，琥珀写「待检查」「需设备验证」或「需官方验证」。字用 Tab 字号，贴压在名片背后，形状见 Shapes。
- 索引贴、名片底栏的状态词、「需处理」页签的筛选和提示带用同一套判定；贴上的字与状态词完全相同。
- 合上的册子在账号库面板上缘插一枚墨色索引贴，写账号库状态：已锁定、未初始化或缺少密钥。这是索引贴在名片之外唯一的用处。
- 强制颜色模式下索引贴加 1px CanvasText 边框。

### 取出名片

- 点「管理 >」，view transition 在 300ms 内（缓动 cubic-bezier(.2, .8, .2, 1)）把同一张名片从册页移到桌面区并放大，页面其余部分 180ms 交叉淡入。名片原来的格位留下一个虚线空位，写「某某 的名片已取出」，附「放回」。
- 「放回名片册」或空位上的「放回」把名片沿原路送回。宽度不超过 1180px 时桌面区在册页上方，取出后页面滚动到桌面区。
- 减少动态效果或浏览器不支持时直接切换。

**「取出与放回」规则。** 处理一张名片就是把它取出：同一张名片移到桌面区，原位留下写着谁的名片已取出的空位；同一时间桌面区只放一张名片或一个添加账号面板。

### 空位

- 1.5px `line` 虚线、`card` 圆角、最低 228px 高，内容居中、`ink-2` 字。网格末尾的「扫码添加账号」空位是整块按钮，带 20px 加号，悬停时虚线转为米游社蓝、文字转为 `accent-ink`。
- 空册子：居中三个 96×60px 的小格（`inner` 圆角），两侧是虚线空位、中间一张带卡纸投影的实心卡纸；下方是 17px 标题「还没有绑定账号」、一句说明和主按钮「扫码添加账号」。

### 批量操作条

- 勾选至少一张名片，或有一批结果待看时出现，粘在册页底部；卡纸底、`card` 圆角、内边距 10px 12px 12px 16px，带批量操作条投影。
- 工具行：650 字重的「已选 N 个账号」，安静按钮「检查所选」「刷新所选凭据」「清理所选失效（N）」，靠右的「取消选择」，下方一行 `ink-2` 说明。

### 头像

- 统一的圆形头像，对读屏隐藏，名字始终以文字出现在旁边。底层是六色首字（按聊天用户 ID 取色；首字是昵称首字或 QQ 号后两位，字号为头像的 38%）；QQ 用户的真实头像从 `q1.qlogo.cn` 经 HTTPS 懒加载、不发送来源页信息，盖在上面，加载失败时露出首字。QQ 官方机器人的用户只有 openid，只显示首字。
- 尺寸：名片 48px、取出的名片 60px、添加账号时的主人预览 36px、绑定对象与跨聊天关联 32px。

### 添加账号

- 桌面区里先是分段切换「米游社扫码 / 导入 Cookie」。扫码：填写聊天用户 ID（是 QQ 号时左侧实时显示 36px 头像），主按钮「获取米游社二维码」；之后一行「为 某某 绑定米游社账号」，下方 220px 的二维码始终印在白底上（10px 内边距、`card` 圆角、卡纸投影），暗色主题也不反色，下方是状态、提示、错误与各游戏的角色发现结果。
- 导入 Cookie：聊天用户 ID、地区、Cookie 三个字段与主按钮「加密导入」，进行中显示等宽的角色发现进度。

### 确认

- 移除整张名片（单个移除或批量清理失效）在模态对话框里确认：最宽 480px，卡纸底、`dialog` 圆角、内边距 24px，对话框投影与 `backdrop` 遮罩；17px 标题写明移除谁的哪个账号，正文说明后果，批量清理时列出要移除的名片；操作靠右，「取消」获得初始焦点，其后是破坏性按钮。
- 移除名片上的一项授权（云游戏授权、跨聊天关联）在原位展开确认条：`tile` 底、`tile` 圆角、内边距 12px 14px，一句后果说明，「保留」或「取消」在前，破坏性按钮在后。
- 重置设备信息需要先勾选确认项，再点次按钮。

### 合上的册子

- 账号库未解锁时只显示账号库面板：卡纸底、`surface` 圆角、内边距 36px（窄屏 24px 20px）、卡纸投影，上缘插墨色索引贴；Headline 字号的标题、`ink-2` 的用途说明（状态由索引贴给出，不再重复）、说明、需要时的密钥保护方式与恢复口令字段，以及一个主按钮（解锁账号库或初始化账号库）。

## Do's and Don'ts

### Do:

- **Do** 让每张名片先回答「这是谁的」：头像、昵称与 QQ 号领头，再列通行证与角色。
- **Do** 在状态词旁印出证据：最近一次检查或刷新的结果与时间，没检查过就写「尚未检查」。
- **Do** 用写字的索引贴挑出要处理的名片：朱红为需重新登录，琥珀为待检查或需验证；贴上的字、名片底栏的状态词与「需处理」筛选保持一致。
- **Do** 在桌面区处理一张名片：放大的名片在上，背面依次是角色、公共查询池、设备、云授权、授权插件与移除账号。
- **Do** 把主题相关的颜色写成 `src/styles.css` 里 `:root` 上的一对 `light-dark()`；`[data-theme]` 只切换 `color-scheme`。
- **Do** 所有图标都用 `src/Icon.vue` 的同一套线描：20px 网格、1.6px 圆头描边、跟随文字颜色。
- **Do** 在粗指针与窄屏下让按钮、输入框、下拉与勾选行至少 44px 高；减少动态效果时取消所有过渡，取出名片直接切换。

### Don't:

- **Don't** 回到「账号表格加状态列」的排法；账号是名片册里的名片。
- **Don't** 把米游社蓝用在状态、计数、页签、勾选、进度条或装饰上。
- **Don't** 给名片的状态词、提示带或计数染红或琥珀；紧急程度只由索引贴表达。
- **Don't** 把索引贴当作标题标签、分节标记或装饰；它只标出需要处理的名片，以及合上的册子。
- **Don't** 在册页上加第二条提示带或横幅。
- **Don't** 让名片悬停抬升，或给它们加宽而软的投影；名片是贴着纸面的白卡纸。
- **Don't** 只用颜色表达状态：索引贴必须写字，状态词写在名片底栏。
- **Don't** 加载外部字体、脚本、样式或 CDN 资源，也不用字符或 emoji 代替图标；外部图片只有经 HTTPS 加载的 QQ 头像。
- **Don't** 在页面内重复宿主标题、插件名称或全局导航。
