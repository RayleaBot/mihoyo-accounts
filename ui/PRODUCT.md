## Platform

web

## Users

- 自托管 RayleaBot 的部署者（机器人管理员）在桌面 Web 管理面中打开插件的“账号管理”，替自己和群友维护绑定在机器人上的米游社 / HoYoLab 账号。（推断）
- 群友是账号的主人，只在聊天中扫码绑定、查询和管理自己的账号，不访问管理页。（推断）
- 页面打开频率低：初始化账号库后，主要在账号失效、需要批量检查或清理、替群友补绑时打开。（推断）

## Product Purpose

插件 `raylea.mihoyo-accounts` 提供米游社扫码登录、加密账号库、三游戏角色发现和 `accounts` v1 服务：一次登录，原神、星穹铁道、绝区零插件共用，游戏插件只拿到业务结果，拿不到凭据。

“账号管理”按机器人账号显示该账号下聊天用户绑定的米游社账号与批量维护；账号库、密钥保护与 ark 令牌是全局设置，同在此页。

成功标准：管理员一眼认出每个账号属于哪位聊天用户（头像、昵称、QQ 号），带着哪些游戏角色，现在能不能用；失效账号的修复与清理只需几步。（推断，依据用户反馈“没有显示绑定的用户信息（QQ、头像、昵称等）”）

## Positioning

账号库是三款游戏插件唯一的凭据来源，凭据加密保存且不离开本插件；管理页是唯一能以人能读懂的方式查看这座账号库的地方。

## Operating Context

- 页面运行在宿主 iframe 中，范围为机器人账号；宿主在页面上方切换机器人账号，页面不重复机器人名称或逐行标注。
- 账号来自聊天中的 `#扫码登录`、管理页“扫码添加账号”（填写聊天用户 ID 后用米游社扫码）或 Cookie 与 SToken 导入。
- 账号主人以聊天用户 ID 标识：OneBot11 下是 QQ 号，宿主在机器人在线时可经 `identities/resolve` 读取昵称与头像（私聊身份读取 `get_stranger_info`），QQ 头像来自 `q1.qlogo.cn` 的 HTTPS 图片；QQ 官方机器人的用户 ID 是 openid，没有公开头像与昵称。
- 账号列表由服务端分页，搜索只作用于当前页；批量检查、刷新、清理失效账号每批最多 128 个，统计分页读取保存摘要。
- 账号详情包含游戏角色、公共查询池状态、设备信息、云游戏授权与允许使用此账号的插件。

## Capabilities and Constraints

- 账号库状态：首次使用、已锁定、已解锁、需要恢复密钥；密钥保护方式为当前 Windows 用户（DPAPI）或 12–128 字节的恢复口令。
- 账号字段：地区（国服米游社 / 海外 HoYoLab）、通行证 ID、状态（可用、需重新登录、待检查）、角色（游戏、昵称、UID、区服、等级）、可否刷新、最近检查结果、公共查询池、云授权、授权插件、更新时间。
- 口令、Cookie、云 Token、设备信息与 ark 令牌都在浏览器中加密后发送，页面从不回显凭据。
- 静态产物随插件包分发；宿主 CSP 只允许同源脚本、样式与字体，图片允许 `self`、`data:` 与 HTTPS。不加载外部脚本、字体或 CDN 资源。
- 不能分发游戏或米游社的字体、图片与商标。（推断，沿用星铁插件的约束）
- 宿主同步的亮暗模式与主题变量是可选输入；宿主 Web 管理面只提供桌面布局，以 1920×1080 为最低分辨率，插件页仍需满足窄屏与粗指针要求。
- 功能、管理动作与请求参数不因视觉改动而变化。

## Brand Commitments

插件名称为“米游社账号”，页面为“账号管理”，ID 为 `raylea.mihoyo-accounts`。作为官方插件，视觉与交互体系由本插件仓库维护，不沿用宿主管理面组件，也不在页面内重复宿主标题、插件名称或全局导航。

## Product Principles

- 先认人，再看号：每个账号首先回答“这是谁的”，再回答“是哪个通行证、带着哪些角色、能不能用”。（推断）
- 状态先于操作：失效与待检查的账号显眼，修复动作就在状态旁边。
- 凭据只进不出：所有凭据输入加密后发送，页面不回显、不提示真实值。
- 破坏性操作明确确认；批量任务显示进度并可停止，已完成的操作保留。
- 账号库锁定或缺少密钥时，页面先引导恢复，再显示账号。

## Accessibility & Inclusion

- WCAG 2.2 AA：正文对比至少 4.5:1，焦点轮廓与相邻背景至少 3:1，颜色不作为唯一信息。
- 全部操作可用键盘完成，焦点顺序与视觉顺序一致；窄屏与粗指针环境的交互目标不小于 44px。
- `prefers-reduced-motion` 下移除非必要过渡，轮询与批量进度保留静态文字；`forced-colors` 下保持可读与可操作。
